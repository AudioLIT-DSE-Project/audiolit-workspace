### Challenges & Solutions

- **Warmed dataset results were unreadable by the UI.** The warmup wrote one payload shape into two cache families whose consumers expected different shapes, so a cache *hit* crashed the request instead of falling back. → Separated the transcript and attention contracts and defined every key family in one place.
- **Custom models silently returned the default model's output.** Several entry points hardcoded a checkpoint while caching under the requested model's name. → Bound the selected model identifier through every loader and made the cache keys model-specific, for both the speech-recognition and emotion families.
- **Fabricated data was being presented as genuine model output** in attention, saliency and the latent projection. → Introduced the provenance contract, removed the random-data fallbacks, and made the faithfulness auditor refuse to score anything not actually measured.
- **Two independently-green changes broke the build in combination.** → Added the rebase-and-re-verify step to the team workflow and a mechanical check that fails when a change deletes something still referenced.
